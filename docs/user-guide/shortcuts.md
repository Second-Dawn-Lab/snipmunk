# Keyboard shortcuts

[Guide overview](index.md)

## From any program

These work while Snipmunk is running (also in the tray). Change them in [Settings](settings.md).

| Shortcut | Action | Change it in |
|---|---|---|
| `Ctrl+Alt+PrintScreen` | Take a screenshot | Settings → Screenshots |
| `Ctrl+Alt+R` | Start or stop a screen recording | Settings → Recording |
| `Ctrl+Alt+G` | Start a new guide | Settings → Documents |
| `Ctrl+Alt+S` | Take a guide step now (while a guide records) | Settings → Documents |
| `Esc` | Cancel a countdown | |

Snipmunk only watches the keys, so another program that uses the same combination reacts too.

## While selecting an area

| Key | Action |
|---|---|
| `1` / `2` / `3` / `4` | Rectangle / Window / Full screen / Freeform (a recording has the first three) |
| `Esc` or right click | Cancel |

## Screenshots mode

### The list

| Key | Action |
|---|---|
| `Ctrl+F` | Search |
| `Ctrl+O` | Open picture files |
| `Ctrl+P` | Print |
| `Ctrl+A` | Select all |
| `Esc` | Clear the selection |
| `←` `→` `↑` `↓`, `Page Up`, `Page Down`, `Home`, `End` | Move through the list (`Shift` extends the selection) |
| `Enter` | Show the capture and select only it |
| `F2` | Rename |
| `Delete` | Delete |
| `Shift+F10` or the Menu key | Open the card's menu |
| `Ctrl`+click, `Shift`+click | Add to the selection, select a range |

### Zoom

| Key | Action |
|---|---|
| `Ctrl+0` | 100 % |
| `Ctrl+1` | Fit to window |
| `Ctrl++` / `Ctrl+-` | Zoom in / out |
| Mouse wheel | Zoom (`Shift`: pan sideways). In "Scroll" mode the wheel pans and `Ctrl`+wheel zooms |
| `Space` + drag, middle button drag | Pan |

### Annotation (the picture has the focus)

| Key | Tool or action |
|---|---|
| `V` | Select |
| `P` / `H` | Pen / Highlighter |
| `E` | Eraser |
| `S` | Shapes |
| `T` | Text |
| `C` | Crop |
| `R` | Rotate right |
| `B` | Blur / redact |
| `Shift` while drawing | Straight line with the pen |
| `Ctrl+Z` | Undo |
| `Ctrl+Y` or `Ctrl+Shift+Z` | Redo |
| `Delete` or `Backspace` | Remove the selected marks |
| Arrow keys (`Shift`: bigger steps) | Move the selected marks |
| `Enter` | Finish the marks, apply a crop |
| `Esc` | Cancel, finish, or go back to Select |
| `Esc` or `Ctrl+Enter` (typing) | Finish a text box |

In **Text actions**: `Ctrl+A` selects all the text, `Ctrl+C` copies the selection.

## Recording mode

| Key | Action |
|---|---|
| `Ctrl+O` | Open a project |
| `Ctrl+S` | Save the project |
| `Ctrl+W` | Close the project or recording on show |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Next / previous tab |
| `F2` | Rename |
| `Space` | Play or pause |
| `←` / `→` | One frame back or forward (`Shift`: one second) |
| `←` / `→` on a trim handle | Move it by 0.1 s (`Shift`: 1 s) |
| `S` (Split mode) | Split at the playhead |
| `Delete` or `Backspace` (Split mode) | Cut out or restore the selected part |
| `Ctrl+Z` / `Ctrl+Y` (or `Ctrl+Shift+Z`) | Undo / redo cuts |

## Documents mode

### The guide

| Key | Action |
|---|---|
| `Ctrl+O` | Open a guide |
| `Ctrl+S` | Save |
| `Ctrl+Shift+S` | Save as |
| `Ctrl+W` | Close the guide |
| `Ctrl+E` | Export |
| `Ctrl+P` | Print |
| `F2` | Rename |
| `Ctrl+Z` | Undo |
| `Ctrl+Y` or `Ctrl+Shift+Z` | Redo |
| `Alt+↑` / `Alt+↓` | Move the selected blocks |
| `Delete` or `Backspace` | Delete the selected mark, or the selected blocks |
| `Esc` | Put away the tool, then the mark, then the selection |
| `Ctrl`+wheel, `Ctrl+0` | Zoom the pages, back to 100 % |
| `Alt`+wheel on a step picture | Zoom that picture |
| `Ctrl+B` / `Ctrl+I` / `Ctrl+U` (in a text block) | Bold, italic, underline |
