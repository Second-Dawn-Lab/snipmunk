# Snipmunk roadmap

Status: Phase 1.

## Phase 1: Repo setup
Project folder, README, license, `.gitignore`, roadmap and icon placeholder.

## Phase 2: App shell
- Widget-style window
- Start with Windows
- Desktop shortcut
- Settings

## Phase 3: Capture
- Global hotkey
- Region, window and full-screen capture
- Red selection pointer
- Multi-monitor and DPI support

## Phase 4: Session gallery
Collect the session's screenshots in the widget window; select, reorder and delete.

## Phase 5: Annotation tools
Mark up screenshots like in Snipping Tool.

## Phase 6: Paste out
- Paste all
- Paste selected
- Drag and drop into other apps

## Phase 7: Sessions, saving and first release
- Sessions and saving (ask to save or auto-save, depending on a setting)
- Installer
- **v0.1.0**: first Windows release

## Phase 8: macOS
**v0.2.0**: macOS support.
